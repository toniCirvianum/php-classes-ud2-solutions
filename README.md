# PHP Classes - UD2 - Solutions

Solutions for the exercises in **01_PHP Classes - Exercises - UD2**.

The repository is organised by exercise:

- `exercise1/` - Basic `Product` class
- `exercise2/` - `User` class with constructor
- `exercise3/` - Classes in separate files with `namespace` and `use`
- `exercise4/` - Inheritance and method overriding
- `exercise5/` - Small MVC-style application

The code intentionally uses **untyped PHP**, matching the classroom exercises.

## Requirements

- PHP 8.x recommended

## Run an exercise

From the repository root, for example:

```bash
php exercise1/index.php
php exercise2/index.php
php exercise3/app/index.php
php exercise4/app/index.php
php exercise5/app/index.php
```
